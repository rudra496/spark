## How to Add Your Project

Open a PR updating this table with:

- Project name
- 1-line description
- Public repository/demo link
- Maintainer handle

## Submission Guidelines

- Project should be active and publicly accessible
- Description should be concise and factual
- No misleading claims or fake metrics
- Include a short "what Spark is used for" statement
- Prefer repositories with CI enabled and a clear license
