# Support

## Getting Help

- **Bugs / Feature Requests**: [Open an issue](https://github.com/rudra496/spark/issues/new/choose)
- **Questions / Ideas**: [GitHub Discussions](https://github.com/rudra496/spark/discussions)
- **Security issues**: See [SECURITY.md](SECURITY.md)

## Response Times

We aim to respond to issues within **3–5 business days**.

## Before Opening an Issue

- Search [existing issues](https://github.com/rudra496/spark/issues)
- Check the [FAQ](docs/FAQ.md)
- Read the [documentation](docs/)
